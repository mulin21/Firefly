## 为什么有这个博客

这是我用自己的域名搭起来的第一个博客,用于记录学习笔记、生活随笔和一些折腾的过程。

## 这个博客是怎么搭起来的

博客基于 [Firefly](https://github.com/CuteLeaf/Firefly) —— 一款基于 Astro 的清新美观静态博客主题模板搭建:

- **框架**:Astro + TypeScript + Svelte + Tailwind CSS,纯静态站点
- **托管**:GitHub Pages,push 代码自动部署
- **构建**:本地或 CI 执行完整构建管线(图片模糊占位、字体子集化、Pagefind 全文搜索索引)
- **域名**:解析到 GitHub Pages,自动 HTTPS

整个过程不需要一台自己的服务器,只需要一个 GitHub 仓库。
